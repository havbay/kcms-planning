# Architecture Decision Records

Use one numbered Markdown file per accepted or superseded architecture decision.

## Required Sections

- Title
- Status: proposed, accepted, superseded, or rejected
- Date
- Context
- Decision
- Alternatives considered
- Consequences
- Verification

## Initial Sequence

- `0001-separate-frontend-and-backend-repositories.md`
- `0002-backend-runtime.md`
- `0003-frontend-runtime.md`
- `0004-authentication-and-session-boundary.md`
- `0005-facebook-comment-source-port.md`

Do not create an empty ADR. Add each file only when the team is ready to record
the evidence and decision.
